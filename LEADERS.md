# For Leaders

Want to run *Midnight in Philippi* with your own youth group? You're welcome to. Everything runs in the browser at **https://midnight-in-philippi.onrender.com**. You don't need to install anything or create an account.

## Leader passcode

The answer key at **https://midnight-in-philippi.onrender.com/lead/answers/** is behind this passcode:

```
thunder-midnight-compass-77
```

Please don't share it with players. If the passcode on the site ever stops working, it has been changed: check this file again for the new one.

## Running the game

Open the site and choose **I'm leading**. That page walks you through the night:

1. **Before:** open the projector backdrop. Players scan its QR code to join, one phone per team.
2. **Start:** read the host story, press <kbd>Space</kbd> on the backdrop to start the timer, and have teams tap **Begin**.
3. **During:** press <kbd>E</kbd> on the backdrop for the earthquake when teams reach Stage 3. Every clue has its own hint button.
4. **After:** press <kbd>D</kbd> on the backdrop to open the debrief questions.

You'll need:

- 4–8 players per team, and one phone per team
- an **NIV** or **NKJV** Bible for each team (teams choose theirs in the app)
- about 40 minutes for the game, plus 10–15 minutes for the debrief
- a projector or TV for the backdrop (optional, but it adds a lot)

## Hosting your own copy

If you'd rather run your own copy, deploy this repo to Render using `render.yaml`, then set your own passcode in the `LEADER_CODE` environment variable. The README lists every setting.
