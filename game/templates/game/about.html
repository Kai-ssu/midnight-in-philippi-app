About

Midnight in Philippi

A Bible escape room for youth groups, based on Paul and Silas in prison in Acts 16:16–34. Teams of 4–8 work through four locked stages with an NIV or NKJV Bible: the accusation, songs at midnight, the earthquake, and the jailer's question, “What must I do to be saved?”

This web app replaces the locked envelopes. Each team opens it on a phone, reads the clue cards, and enters the codes. A projector backdrop sets the scene in the room, and discussion slides lead the group debrief afterwards.

Try it

How it's built

  • Django checks every code on the server, so answers never appear in the page.
  • Progress lives in a signed cookie instead of a database, so it runs free on Render.
  • The unlock animations are pure CSS, and every sound effect is synthesized in the browser with the Web Audio API. There are no image or audio files.
